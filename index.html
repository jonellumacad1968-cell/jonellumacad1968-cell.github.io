Featured Engineering Project

MetroSure — Digital Measuring & Tracking System

Lead Hardware & Embedded Developer

Prototype Stage

An embedded hardware prototype built to accurately measure and track the displacement length of aluminum profiles during manual cutting operations, minimizing manual measurement errors.

Core System Workflow Logic:

  • User inputs target length via TFT touchscreen interface.
  • START command triggers measurement tracking sequence.
  • Measuring wheel coupled with rotary encoder monitors profile feed distance.
  • ESP32 processes pulse feedback and updates display metrics in real-time.
